# Empirical Analysis of Ethereum L2 Optimistic Rollups 

A measurement-driven study of **Ethereum Layer-2 blockchain systems**, focused on **Optimism, Base, and Arbitrum**. The repository analyzes how optimistic rollup architectures translate into observable system behavior across transaction latency, L2-to-L1 finality, fee dynamics, transaction composition, and settlement characteristics.

The analysis is built around reproducible on-chain data collection and processing, enabling consistent comparison across multiple rollup ecosystems rather than relying only on architectural descriptions.

## Analysis Scope

- Transaction latency and confirmation behavior
- L2-to-L1 finality and settlement anchoring
- Fee characteristics and execution costs
- Transaction composition and batching behavior
- Cross-rollup performance comparison
- Reproducible on-chain data processing and visualization

## Repository Structure

- `analysis/scripts/` — data collection, processing, and analytical workflows
- `analysis/data/` — datasets used for evaluation
- `analysis/figures/` — generated plots and visual analysis
- `analysis/report/` — supporting analytical material

The accompanying report develops the broader methodology, theoretical context, and interpretation of the measured behavior across the evaluated Layer-2 systems.
